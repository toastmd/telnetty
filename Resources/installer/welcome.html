Welcome to Telnetty

Telnetty is a small, fast telnet client for macOS, made for MUDs, BBSes, network gear and retro fun.

  • Full telnet protocol: option negotiation, terminal type and window size
  • ANSI colors: 16, 256 and true color
  • Bookmarks, command history, hidden password entry, transcripts
  • Opens telnet:// links

This installer puts Telnetty.app in your Applications folder.
